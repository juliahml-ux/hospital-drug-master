# 衛生福利部嘉義醫院藥品臨床處方集管理系統 (Hospital Drug Formulary & Clinical Master System)

專為醫院藥局、臨床藥師、醫師與護理醫療團隊打造的輕量化藥品主檔維護、臨床處方集查閱、健保給付規定 PDF 整合與 Excel 雙向轉換系統。

---

## 🌟 核心功能亮點

1. **零安裝、點擊即用 (Local-First Single Page App)**：
   - 純前端單一 HTML 檔案架構，免架設伺服器或安裝 Python/Node.js 環境。
   - 資料 100% 保留在使用者本機瀏覽器中，符合醫療個資與院內資料安全規範。

2. **精準 7 大核心欄位規格**：
   - `院內代碼` (Hospital Code)：支援大寫代碼自動格式化與防重複檢查。
   - `健保代碼` (NHI Code)：即時檢核是否符合台灣健保署標準 10 碼英數字格式。
   - `英文商品名` (Brand Name)
   - `中文品名` (Chinese Name)
   - `學名/主成分` (Generic Name)
   - `規格劑量` (Strength / Spec)
   - `劑型` (Dosage Form)：內建常用臨床劑型快速選單（錠劑、膠囊、注射劑、吸入劑、外用膏劑等）。

3. **即時檢核與儀表板指標 (KPI Dashboard)**：
   - 總建置品項數統計。
   - 健保碼長度異常（非 10 碼）警示。
   - 院內代碼重複項目紅字標記。
   - 必填欄位完整性狀態追蹤。

4. **強大 Excel 雙向支援 (Powered by SheetJS)**：
   - **一鍵下載標準範本**：自動產出包含表頭與臨床範例之 `.xlsx` 範本。
   - **智慧批次匯入**：自動識別多種表頭同義詞（如「院內碼」、「健保代碼」、「品名」、「成分」等）。
   - **重複衝突處理機制**：匯入遇重複代碼時，彈窗提示比對，支援「全部覆蓋更新」或「略過重複」。
   - **一鍵匯出 Excel**：自動依當日日期命名（如 `醫院藥品主檔與代碼清單_20260905.xlsx`）。

5. **自動儲存 (LocalStorage)**：
   - 編輯或匯入之資料自動同步至瀏覽器本機儲存空間，避免誤關分頁造成資料遺失。
   - 內建台灣常見臨床藥品示範資料，隨時可一鍵重設或清空。

## 📑 欄位定義與規範

| 欄位名稱 | 英文對照 | 必填 | 格式與檢核規則 | 範例 |
| :--- | :--- | :---: | :--- | :--- |
| **院內代碼** | Hospital Code | 是 | 英數字組合，院內唯一不重複 | `ONORV5` |
| **健保代碼** | NHI Code | 是 | 固定 10 碼英數字（台灣健保標準代碼） | `BC19248100` |
| **英文商品名** | Brand Name | 是 | 藥品英文原廠/學名商品名與劑量 | `Norvasc Tablets 5mg` |
| **中文品名** | Chinese Name | 否 | 衛福部核准中文藥名 | `脈優錠 5 毫克` |
| **學名/成分** | Generic Name | 是 | 主要活性成分 (Active Pharmaceutical Ingredient) | `Amlodipine besylate` |
| **規格劑量** | Strength/Spec | 否 | 單一劑量包裝含量 | `5mg/tab` |
| **劑型** | Dosage Form | 否 | 藥物劑型分類 | `錠劑 (Tablet)` |

## 🚀 快速開始使用

1. 在檔案總管中直接**按兩下開啟 `index.html`**（支援 Chrome、Edge、Firefox、Safari 等現代瀏覽器）。
2. **測試功能**：系統預載 10 筆台灣常見臨床藥品，可直接體驗搜尋、篩選、編輯與匯出。
3. **匯入現有資料**：
   - 點擊頂部「**下載標準範本**」取得 Excel 範本。
   - 將院內藥品資料填入後，點擊「**匯入 Excel**」即可快速完成建立。
4. **匯出資料**：隨時點擊「**匯出 Excel**」儲存最新主檔備份。

## 🔒 醫療資訊安全與隱私聲明

本工具所有資料處理、Excel 解析及暫存皆在**使用者本機瀏覽器記憶體 (Client-Side)** 中執行，**不會**將任何藥品代碼或院內機密資料傳送至外部伺服器。
